# Professionals

Local services marketplace: customers post requests, nearby professionals send offers, the
customer accepts one and the job is tracked through to a review.

| Folder | What |
|---|---|
| [`frontend/`](frontend/README.md) | Expo / React Native app (iOS, Android, web) |
| `backend/` | Express API (MongoDB, Redis, Cloudinary) — in progress |

The Android APK is built by the manual GitHub Action `.github/workflows/android-apk.yml`
(Actions → Android APK → Run workflow), from `frontend/`.
